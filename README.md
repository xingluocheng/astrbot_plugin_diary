# 大肥鱼的日记 · astrbot_plugin_diary

> 让机器人自己写日记，存到桌面，聊天时还能想起来 · AstrBot 插件
> 全自动，没有指令。

---

## 一、这是什么

给机器人一本自己的日记。

它会把聊天里发生的事攒起来，每隔十几个到几十个小时写一篇日记——记下那段时间主要发生了什么、哪件事有意思、她当时干了什么。

写完之后，最近几篇日记会自动进入她的上下文：下次聊天她"记得"这些事，能主动提起，而不是每次从零开始。

和向量库式的记忆插件不同，这里的产物是**人能直接读的 markdown**：一天一个文件，打开就能看。

---

## 二、功能

| 功能 | 说明 |
|---|---|
| 自动写日记 | 攒够消息 + 到间隔时间，自己写一篇，不需要指令 |
| 启动补写 | AstrBot 每次启动 15 秒后，用最近 N 条补写一篇 |
| 存到桌面 | `桌面\大肥鱼日记（不要删除）\`，一天一个 markdown |
| 自动重建 | 文件夹被删了，下次启动自动创建回来 |
| 上下文注入 | 最近几篇日记注入 system prompt，聊天时真的想起来 |
| 记录双方 | 主人的话 + **她自己的回复**都进素材，不只是一面之词 |
| 亲密度联动 | 装了「亲密度」插件的话，关系够亲密的朋友也能进日记 |
| 指令过滤 | `reset` / `help` / `/空间` 这类指令不进素材，不占字数 |
| 防重复 | 按时间戳记账 + 批次指纹去重，重启/热重载都不会把同一批写两遍 |

## 三、安装

### 方式一：在 AstrBot 面板里装（推荐）

面板 → **插件** → **从 GitHub 安装**，填：

```
xingluocheng/astrbot_plugin_diary
```

### 方式二：命令行

```bash
cd AstrBot/data/plugins
git clone https://github.com/xingluocheng/astrbot_plugin_diary.git
```

装完重启 AstrBot。第一次启动时它会自动在桌面建好日记文件夹。

## 四、⚠️ 怎么改成你自己的 QQ 号

**这是装完必须做的第一步，不做的话日记不会记任何东西。**

### 两个号要分清

| 号 | 是什么 | 在哪改 |
|---|---|---|
| **大肥鱼（机器人）的 QQ** | 机器人登录的那个号，日记写的是它的经历 | 配置项 `bot_ids`。留空 = 自动用当前登录号并排除她自己发的消息；填了按这个号过滤 |
| **主人的 QQ** | 你的个人号，只有你说的话才会被当成「主人」记下来 | 插件的 `owner_ids` 配置 |

### 改法 A：在面板里改（推荐）

面板 → 插件 → 大肥鱼的日记 → **配置** → 找到 `owner_ids`：

```
3640280199      ← 把它改成你自己的 QQ 号
```

多个用英文逗号分隔：`123456789,987654321`

### 改法 B：直接改配置文件

```
AstrBot/data/config/astrbot_plugin_diary_config.json
```

```json
{
  "owner_ids": "你的QQ号"
}
```

### 不改会怎样

`owner_ids` 留空 → 退回 AstrBot 管理员判定 → 而 `admins_id` 默认是 `["astrbot"]`，不是 QQ 号，**永远匹配不上**。结果：缓冲里一条都记不到，永远不会写日记。

## 五、使用方法

这个插件**故意不注册任何指令**，你正常聊天就行。

### 触发条件

| 时机 | 取多少条 | 条件 |
|---|---|---|
| AstrBot 启动 | `startup_messages`（默认 40） | 至少攒够 `min_messages`（默认 30）条没写过的新对话 |
| 运行中定时 | `max_messages_per_diary`（默认 120） | 到 `interval_hours`（默认 24）且攒够 30 条 |

两者都会跳过已经写过的内容，不会重复写。

### 什么会被记下来

- ✅ 主人说的每一句话（默认只记私聊）
- ✅ **她自己说的每一句话**
- ✅ 关系够亲密的朋友（需要装亲密度插件）
- ❌ 群聊（`private_only` 打开时）
- ❌ 指令消息和指令回复（`reset` / `help` / `/空间` 等）

### 日记长什么样

```
C:\Users\<你>\Desktop\大肥鱼日记（不要删除）\
├── 与主人的美好记忆\        ← 主人的日记（文件夹名可配置）
│   ├── 20261102-0013.md
│   └── index.md
├── 小晴\                    ← 亲密朋友的日记，用 QQ 昵称当文件夹名
│   ├── 20261102-0105.md
│   └── index.md
└── index.md                 ← 总索引：每个文件夹几篇
```

单篇格式：

```markdown
---
date: 2026-10-31 16:47
range: 10-31 16:31 ~ 10-31 16:36
messages: 4
mood: 有点心疼，又有点想被夸
title: 修车人蹲在路灯下
tags: 加班, 旧自行车, 大白饭
---

# 修车人蹲在路灯下

正文……
```

## 主人的日记权限（不用指令）

直接说人话，她自己调工具：

| 你说 | 效果 |
|---|---|
| 现在都给谁写日记？ | 列出名单，标出谁开着谁关了 |
| 别给小晴写日记了 | 关掉小晴 |
| 恢复给小晴写日记 | 重新打开 |

关掉之后：和她/他聊天时不写、也不读那人的日记；**已写好的文件不删**。只有主人能改。

## 六、配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `owner_ids` | **空** | **必填**，主人 QQ 号 |
| `bot_ids` | **空** | 大肥鱼的 QQ；留空自动用登录号并排除她自己的消息 |
| `private_only` | 开 | 只记私聊 |
| `record_self` | 开 | 记她自己的回复 |
| `ignore_commands` | 开 | 过滤指令消息（含 `/亲密度` `/好感度` `/空间` 等） |
| `include_intimate` | 开 | 亲密度够的人也进日记 |
| `owner_folder` | 与主人的美好记忆 | 主人的日记文件夹名 |
| `intimate_days` | 14 | 多少天算亲密（要和亲密度插件一致） |
| `startup_write` | 开 | 启动时补写 |
| `startup_messages` | 40 | 启动补写取多少条 |
| `interval_hours` | 24 | 运行中每隔多久检查 |
| `min_messages` | 30 | 攒不够就跳过 |
| `max_messages_per_diary` | 120 | 单篇最多参考多少条 |
| `inject_enabled` | 开 | 是否注入上下文 |
| `inject_recent` | 2 | 注入最近几篇 |
| `inject_max_chars` | 1500 | 注入字数上限 |
| `retention_days` | 0 | 0=永久保留 |
| `diary_voice` | 第一人称随手写 | 决定日记的文体 |

### 省 token 的建议

- `inject_max_chars` 是**每轮对话都扣**的，比写日记更费。1500 → 800 能省一半
- `inject_recent` 2 → 1 也行
- `min_messages` 调大，写得更少

## 七、和「大肥鱼的亲密度」联动

两个插件是上下游：

```
亲密度插件 → 按聊天天数判断谁够亲密 → 写进 users.json
                                        ↓ 读取
本插件     → 够亲密的人也能进日记
```

| 装了什么 | 效果 |
|---|---|
| 只装本插件 | 日记里只有主人 |
| 只装亲密度 | 她说话会分亲疏，但日记还是只有主人 |
| 两个都装 | 日记里会出现「小晴」这样的亲密朋友，称呼自动区分 |

⚠️ 门槛要对齐：本插件的 `intimate_days` 要等于亲密度插件的 `close_days`（默认都是 14）。

读不到亲密度数据时不会报错，自动降级成「只记主人」。
